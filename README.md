# Command TV Dashboard

## Overview

Command TV Dashboard is an interactive web application that visualizes YouTube analytics through dynamic charts and dashboards. The application presents insights such as the countries with the most YouTubers, most-liked channels, most-viewed categories, and other key YouTube statistics using interactive data visualizations.

---

## Features

- Interactive dashboard displaying YouTube analytics
- Dynamic data visualization using D3.js
- Charts for countries with the most YouTubers
- Most-liked YouTube channels analysis
- Most-viewed YouTube categories
- Responsive and user-friendly interface

---

## Technologies Used

- JavaScript
- D3.js
- HTML5
- CSS3
